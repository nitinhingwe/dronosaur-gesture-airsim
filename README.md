# Dronosaur AirSim Bridge

Raspberry Pi 5 gesture-control bridge for AirSim simulation.

## Current Working Version
- gesture_airsim_v5.py

## Purpose
USB Camera -> Raspberry Pi 5 -> Gesture Detection -> AirSim Drone Control

## Safety
- No hand / unknown gesture = hover
- Emergency land = l
- Quit = q
